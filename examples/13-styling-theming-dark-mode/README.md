# 13 — Styling, Theming & Dark Mode 🫟

Demonstrates token-based color palettes, instant theme switching, and WCAG AA contrast compliance across light and dark modes.

```
┌──────────────────────────────────────┐
│ 🫟 13 — Styling, Theming & Dark Mode │
├──────────────────────────────────────┤
│ Active Theme: Light Mode ☀️          │
│ Liquid themes map directly to native │
│ view background and text colors...   │
│ [Switch to Dark Mode]                │
└──────────────────────────────────────┘
```

## How It Works
- Style normalizer preserves scoped CSS classes and resolves colors into native ARGB hex codes.
- Dynamic class bindings update the view tree with fine-grained delta operations.
